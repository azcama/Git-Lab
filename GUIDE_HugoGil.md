# Git Practice Guide - Hugo Gil

## Branch Creation
I created the new feature branch with mi name using:
`git checkout -b feature/Hugo-Gil`

## Staging and Committing
To staged the changes and new files I used:
`git add .`

Whatever I committed the changes with:
`git commit -m "message"`

## Merge Conflict Resolution
A merge conflict happens when Git cannot merge changes.
To solve it, I edited the conflicting files,
removed the conflict markers, and committed.
