# Git Practice Guide

## Branch Creation

To create my feature branch, I used the following commands:

git checkout develop  
git pull origin develop  
git checkout -b feature/tu-nombre  

## Staging and Committing Changes

After creating the documentation file, I staged and committed the changes using:

git add GUIDE_tu_nombre.md  
git commit -m "Add Git practice guide documentation"

## Merge Conflict Resolution

To resolve a merge conflict, I followed these steps:
1. Pulled the latest changes from the develop branch.
2. Identified the conflicting files.
3. Manually edited the files to keep the correct content.
4. Added the resolved files and committed the changes.

In this practice, I did / did not face a merge conflict.  
If I faced one, I solved it by manually editing the conflicting file and committing the resolution.
